# Level05 — estructuras y evaluación avanzada

## Objetivos

- Detectar ciclos y validar estructuras anidadas.
- Evaluar expresiones controlando desbordes de pila y operadores inválidos.
- Representar memoria y máscaras de bits con formato exacto.

## Método

Expresa el algoritmo como estados y transiciones. Identifica explícitamente
errores de sintaxis, divisiones por cero, ciclos y tamaños parciales de bloque.

## Comprobación personal

Prueba estructura vacía, anidamiento incorrecto, expresión incompleta, opciones
duplicadas y bloques de memoria de 0, 1, 15, 16 y 17 bytes.
