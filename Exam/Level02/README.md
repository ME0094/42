# Level02 — conversiones y bits

## Objetivos

- Trabajar con bits, duplicación y comparación de cadenas.
- Convertir texto numérico respetando espacios y signo.
- Resolver intersección, unión y subsecuencias sin duplicados accidentales.

## Método

Usa tablas pequeñas para visualizar octetos y casos con caracteres repetidos.
Para funciones numéricas incluye cero, uno, negativos cuando correspondan y
límites del tipo utilizado.

## Comprobación personal

Verifica resultados exactos y prueba entradas inválidas o incompletas. Comprueba
que toda memoria reservada tenga propietario y liberación clara en el arnés.
