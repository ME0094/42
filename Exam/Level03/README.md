# Level03 — algoritmos intermedios

## Objetivos

- Manejar rangos, bases, divisores, primos y mínimo común múltiplo.
- Normalizar palabras y capitalización con espacios irregulares.
- Recorrer listas enlazadas sin perder nodos.

## Método

Separa análisis, condición límite y recorrido. Antes de programar, escribe casos
para cero, igualdad, orden ascendente y descendente, y entradas vacías.

## Comprobación personal

Traza a mano al menos una ejecución completa. Compila con advertencias tratadas
como errores y comprueba los arrays dinámicos con Valgrind.
