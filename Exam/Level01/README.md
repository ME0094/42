# Level01 — cadenas y punteros

## Objetivos

- Recorrer, copiar, medir y transformar cadenas terminadas en `\0`.
- Modificar valores mediante punteros.
- Validar el número exacto de argumentos antes de acceder a ellos.

## Método

Dibuja índice, carácter actual y condición de parada. Después prueba letras en
ambos extremos del alfabeto, dígitos, signos, espacios y la cadena vacía.

## Comprobación personal

Reimplementa cada función desde su prototipo y prepara un `main` mínimo propio.
No memorices el código: justifica cada acceso y cada incremento.
