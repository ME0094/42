# Proyectos

Se creará un subdirectorio por cada proyecto permitido de 42.

Antes de confirmar cambios:

- comprobar que el material puede conservarse en un repositorio privado;
- eliminar credenciales, datos personales, binarios generados y artefactos de evaluación;
- documentar cómo compilar, ejecutar y verificar el proyecto;
- mantener el trabajo de UoPeople exclusivamente en `ME0094/uopeople-cs`.

## Qué aprendí

Esta carpeta define el criterio de organización para futuros proyectos: un
directorio independiente, instrucciones reproducibles y separación clara entre
código fuente, documentación y artefactos generados. Todavía no contiene un
subproyecto que permita documentar aprendizajes técnicos concretos.

## Dificultades

El reto actual es de gobernanza del repositorio: verificar qué material puede
publicarse, mantener fuera credenciales y datos personales y no mezclar trabajos
de otros programas académicos. Estas reglas se aplicarán antes de incorporar el
primer proyecto.
